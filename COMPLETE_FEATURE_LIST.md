### 2. **Emergency Protocols** 📋
**Location:** Home → "What To Do" tile

**5 Different Scenarios:**
1. **Police Emergency**
   - For: Immediate danger, assault, threats
   - Number: 911
   - Steps: Call → Location → Description → Follow dispatcher

2. **Harassment/Threatening Behavior**
   - For: Being followed, threatened, harassed
   - Number: 911
   - Steps: Go public → Call 911 → Take photos → Get witnesses → File report

3. **Stalking/Suspicious Following**
   - For: Someone following you or watching
   - Number: 911  
   - Steps: Don't go home → Call police → Well-lit area → Note description → Police escort home

4. **Physical Assault**
   - For: Being attacked or harmed
   - Number: 911
   - CRITICAL: Don't shower (preserves evidence) → Hospital check → Evidence collection

5. **Medical Emergency**
   - For: Medical urgency or injury
   - Number: 911
   - Steps: Call 911 → State condition → Location → Follow dispatcher

**Features:**
- ✅ Big red "CALL NOW" button
- ✅ Step-by-step instructions (numbered, clear)
- ✅ What NOT to do (important for evidence)
- ✅ Why each step matters
- ✅ Easy to read in panic situation
